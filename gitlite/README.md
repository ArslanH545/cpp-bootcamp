## What I learned
`List` owns the chain of heap nodes through `head`; each `node->next` is owned by the node before it. I wanted to know which copy ctor I need, deep or shallow, so I ran a small experiment: built a list with three nodes, copied it with the compiler's default copy ctor, and let both destruct. ASan aborted with heap-use-after-free: freed by one `~List()`, read by the other, same `main.cpp` line — two objects, one chain. The default copy ctor copies the `head` pointer, not the nodes, so both lists owned the same allocation. The fix is a deep copy: the copy ctor starts empty and `push_back`s every value from `other`, so each list gets its own nodes and exactly one owner per node. ASan is silent now.
